## About Wanderlust
Wanderlust is a web application designed for discovering and listing travel destinations. Users can browse listings, view details, and explore various locations seamlessly.

## Features
- Browse and view travel listings
- User-friendly interface
- Hosted on Render 

## Technologies Used
- Node.js
- Express.js
- MongoDB
- HTML, CSS, JS
- Cloudinary
- MapBox
